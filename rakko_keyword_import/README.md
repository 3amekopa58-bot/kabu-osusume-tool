# ラッコキーワード抽出ツール

ラッコキーワードで見つけたキーワードを、重複を除いて一覧化するための
単体で動く Google Apps Script。他のツールへの組み込みは前提にしていない。

## なぜ完全自動化ではないか

ラッコキーワード ([https://related-keywords.com/](https://related-keywords.com/)) は無料版・PRO版とも
外部プログラムから叩ける公式APIを提供していない。プログラムで自動的に
ページを読み込んでキーワードを抜き出す（スクレイピング）ことは利用規約で
禁止されている可能性が高く、アカウント停止等のリスクがあるため今回は避けた。

代わりに、ラッコキーワードの画面上の「コピー」機能で人が手動でコピーし、
貼り付けた後の整形・重複排除・一覧化だけを自動化する（半自動抽出）。

## セットアップ

1. 新規にGoogleスプレッドシートを1つ作る（このツール専用でよい）
2. 「拡張機能」→「Apps Script」を開く
3. `KeywordImport.gs` の内容を貼り付けて保存
4. スプレッドシートを再読み込みすると、メニューに「ラッコキーワード取込」が追加される
   （初回のみ、Apps Scriptの実行権限の承認が必要）

## 使い方

1. ラッコキーワードで検索し、結果一覧を「全キーワードコピー」ボタン、または
   範囲選択してコピーする
2. スプレッドシートの「取込用」シート（無ければ自動作成される）のA列に貼り付ける
   - 1行1キーワードでも、カンマ区切り・読点区切りでもOK
3. メニュー「ラッコキーワード取込」→「取込用シートから追加」を実行
4. 「キーワードリスト」シートに、重複を除いて新しいキーワードが追加される
   - 列構成: `キーワード` / `ステータス`（未使用・使用済み） / `取込日`
   - 取込用シートの内容は実行後にクリアされる

抽出したキーワードは「キーワードリスト」シートにたまっていくので、
そこから必要な分だけ他のツールへコピーして使う。
