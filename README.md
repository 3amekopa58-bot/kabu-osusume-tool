# 株おすすめツール（自分専用・MVP）

日本株を対象に、「割安度（PER・PBR・配当利回り）」と「トレンド（移動平均・RSI）」を
スコア化して合算し、おすすめ順にランキングするツール。

## 使い方

```bash
cd "/Users/kopamon/Documents/株おすすめツール"
source venv/bin/activate
python3 screen.py
```

`output/recommend_YYYYMMDD.csv` にランキング結果が出力される（Excelで開ける形式）。

## 現状（MVP）

- 対象銘柄: `tickers.csv` に列挙した主要30銘柄（TOPIX Core30相当の大型株）
- データ取得: yfinance（無料・登録不要）
- スコア: 割安度スコアとトレンドスコアを 50:50 で合算（`screen.py` の
  `FUNDAMENTAL_WEIGHT` / `TECHNICAL_WEIGHT` で調整可）

## 今後の拡張候補

- **対象銘柄を増やす**: `tickers.csv` に行を追加するだけで対象が増える。
  東証プライム全銘柄にする場合はJPXの上場銘柄一覧を取り込む処理が別途必要。
- **業種別の比較**: 現状は全銘柄まとめて偏差値化しているため、業種によって
  PER水準が違う点は考慮していない。業種内での相対評価に変えると精度が上がる。
- **決算・ニュースの考慮**: 直近決算のサプライズや業績修正を加点/減点材料にする。
- **定期実行**: 毎朝自動で回して結果をSlack等に送るなど（希望があれば設定）。
- **バックテスト**: このスコアで過去に選んでいたら実際どうだったかを検証する。

## 注意事項

- **自分専用ツールとして作成**。個別銘柄の売買を推奨するものではなく、
  スクリーニング（絞り込み）の参考情報として使うこと。
- 投資判断は自己責任で。他人に見せる/配布する場合は、投資助言業の
  規制（金融商品取引法）に抵触しないよう表示内容に注意すること。
- yfinanceのデータは無保証・遅延あり。重要な判断の前には証券会社の
  公式情報で必ず裏を取ること。
