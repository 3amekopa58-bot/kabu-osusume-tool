# 株おすすめツール（自分専用）

日本株（全上場から絞った944銘柄）を対象に、「割安度（PER・PBR・配当利回り）」と
「トレンド（移動平均・下半身・押し目買い等）」をスコア化して合算し、
おすすめ順にランキングするツール。

---

## ⚠️ 最初に読むこと：インデックスに勝てるとは考えないこと

予算制約・売買手数料・スリッページ・ETFコスト・**税金**をすべて織り込んだ
ポートフォリオシミュレーション（`portfolio_sim.py`）の結果。
数値は複数試行の平均と範囲（**1回の実行に再現性がないため**。後述）。

| 期間（税引き後） | 日経225の225銘柄 | 944銘柄に拡大 | 日経平均を買い持ち |
|---|---|---|---|
| 5年 | +108.8% | +130.4%（117〜140） | +109.9% |
| 10年 | +157.5%（145〜170） | +302.1%（264〜351） | +235.2% |
| 26年 | +144.0%（142〜146） | +310.9%（252〜358） | +224.9% |

- **対象銘柄を日経225から944銘柄へ広げると成績が大きく改善する**
  （`universe.csv`）。予算100万円では大型株ほど買えず、資金の6割が
  遊んでいたことが最大の敗因だった。シグナルの質は同等で、数が4.4倍になる
- 拡大後は全期間・全試行でインデックスを上回った
- **生存者バイアスは実測した結果、無視できる規模だった**（4.4-9）。
  `universe.csv`は「今日買えて今日流動性がある」銘柄で作っているため
  上場廃止銘柄が入っていないが、JPXの公式データで調べると2017〜2025年の
  上場廃止643件のうち**95.6%は買収・MBO**（株主はプレミアムを受け取る）で、
  **経営破綻は1.7%**しかない。破綻による過大評価は最悪ケースでも
  期待値-0.005pt。むしろ「買われて上がった銘柄」が抜けているぶん、
  バイアスの向きは戦略に**不利**だった
- ⚠️ **ただし26年の数値は根拠として弱い**。①JPXのアーカイブは2017年以降
  しかなく、2001-2003・2008-2009の高倒産率時代のバイアスは未検証、
  ②経路依存のノイズが±50ptある。**採用判断は5年・10年を主の根拠にすること**
- **1回の実行の数値を信じないこと。** 株価0.01%（1,000円の株で0.1円）の
  誤差で26年の結果が±50pt動く。比較するときは`analyze_sensitivity.py`で
  範囲を出すこと
- 詳細は [REQUIREMENTS.md](REQUIREMENTS.md) の 4.4-8 / 4.4-9 / 6.6-2 を参照

**それでも「インデックスより確実に儲かるツール」とは考えないこと。**
検証は過去データ上のものであり、将来の相場で同じ優位が続く保証はない。
個別株を自分で選びたい人が、機械的な基準で候補を絞るための道具として使うこと。

## 現在の仕様

- **対象銘柄**: `universe.csv` の944銘柄（全上場3,822銘柄から「予算内で買える」
  「1日の売買代金1億円以上」で絞ったもの。`scripts/build_universe.py`が生成）。
  日経225だけを見ていた頃は、予算100万円で買えない大型株が多く資金の6割が
  遊んでいた（REQUIREMENTS 4.4-8）
- **予算**: 100万円（`screen.py` の `BUDGET`）。日本株は100株単位で買うため、
  1単元が予算を超える銘柄は自動で除外される
- **データ取得**: yfinance（無料・登録不要）＋ EDINET（財務データの一部）
- **スコア**: 割安度スコアとトレンドスコアを 50:50 で合算
  （`FUNDAMENTAL_WEIGHT` / `TECHNICAL_WEIGHT` で調整可）

### 売買ルール（バックテストで検証済み）

- **買い**: 「下半身」または「押し目買い」のどちらかが点灯し、かつ
  PPP3/4以上・株価が100日線より上・日経平均がADX20超の上昇トレンド・
  出来高が20日平均の1.5倍以上・日経平均をアウトパフォーム中
- **売り**: 保有60日で手仕舞い、または買値から-10%で損切り（早い方）
- **空売りはやらない**: 逆下半身・戻り売りを実装して検証したが、26年
  4,081トレードで勝率39.1%・平均-1.77%と明確に損失だった（4.4-6参照）

### 944銘柄を扱うための2段階スクリーニング

Yahooの財務データ（`info`）は1銘柄1リクエストで、944銘柄ぶん投げると
レート制限（Too Many Requests）で全滅する。そこで：

1. **第1段階（通信なし）**: 株価を一括取得し、944銘柄すべてをテクニカル評価
2. **第2段階（通信あり）**: テクニカル上位120銘柄だけ財務データを取得

圏外の銘柄は総合スコア（割安度50%＋トレンド50%）で上位に来る余地がないため
実質の取りこぼしはない。ただし**割安度スコアは「対象銘柄内での相対順位」**
なので、母集団が944ではなく120になる点は仕様として意識すること。

⚠️ **`screen.py` が落ちた日は通知が「本日のスクリーニングが完了していません」に
変わる。** ワークフローは notify を `if: always()` で呼ぶので、日付を確認しないと
前日の推奨が今日のものとして届いてしまう（2026-08-30に実際に発生）。

⚠️ 財務データが3割超で取れなかった場合は警告が出る。欠損は中立（0.5点）
として扱われるため、黙って進むと「テクニカルだけで選んだ結果」が
通常の推奨に見えてしまう。警告が出たら時間を置いて再実行すること。

### 自動実行と通知

平日朝8時（JST）にGitHub Actionsで`screen.py`を実行し、上位3銘柄を
ntfy.sh でプッシュ通知する（トピック名はGitHub Secretsの`NTFY_TOPIC`）。

**◆本命と◇参考を分けて通知する**（2026-08-30〜）。バックテストの成績
（勝率60.6%・PF2.65）は採用ルールの5条件がすべて揃った場合の数字なので、
一部しか満たさない銘柄に当てはめてはいけない。混ぜずに分けて出す。

```
本日のおすすめ（すべて現物買い）

◆本命（全条件を満たす銘柄）: 本日はなし

◇参考（条件を一部満たす）※成績の裏付けは弱い

[9934]因幡電機産業株式会社[押し目]
  買い 3,062円 × 100株 = 306,200円
  利確目安 3,242円(+5.9%) = +17,964円
       到達率69% / 到達なら約10営業日（4〜18日）
  損切り  2,756円(-10%) = -30,620円 ※到達30%
  期限 保有60日で手仕舞い
  条件 4/5 ・未達: 日経がADX20超の上昇
```

**★片山流は別系統として末尾に出す**（2026-08-30〜）。買う位置が正反対
（押し目 vs 新高値）で、割安度と成長性も逆方向に働くため、同じスコアに
混ぜると打ち消し合う。**利確目標も期限も置かず損切り-8%**という別の運用
ルールで表示する（REQUIREMENTS 4.4-14/15）。

条件は**書籍版と検証版の2種類を併記**している。書籍に明記された条件と、
このツールの検証で最も成績が良かった条件が**PERで正反対**になるため
（著者は「PER30倍台まで買い」、こちらの検証では30倍台がPF0.50）。
母集団が違う（著者はグロース市場の中小型株、こちらは944銘柄）ことが
原因と見ており、どちらが実運用で機能するかを見るために両方出す。

| 版 | 条件 | 14年成績 |
|---|---|---|
| 書籍版 | 増収10%↑・増益20%↑・**ROE10%↑**・PER39倍以下 | 388件 PF2.96 |
| 検証版 | 増収10%↑・増益30%↑・PER20倍未満 | 576件 PF3.04 |

```
★片山流・書籍版（増収10%↑・増益20%↑・ROE10%↑・PER39倍以下） 3件

[6750]エレコム株式会社[新高値]
  買い 2,007円 × 100株 = 200,700円
  増収+12% / 増益+26% / PER7.8倍 / ROE19%
  損切り  1,846円(-8%) = -16,056円
  利確目標なし・期限なし（上昇が続く限り持つ）
```

⚠️ 片山流の候補は押し目狙いのテクニカルスコアでは上位に来ないので、
`screen.py` は**圏外の候補も財務データの取得対象に加えている**。
これを外すとPERが埋まらず、判定が常に不成立になる。

実測すると、本命を絞り込んでいるのは実質2条件だけだった
（残り3条件は120銘柄中118〜120銘柄が充足）：

| 条件 | 充足 |
|---|---|
| 日経をアウトパフォーム / 買いシグナル / PPP3/4以上 | 118〜120 / 120 |
| **出来高が20日平均の1.5倍以上** | **19 / 120** |
| **日経がADX20超の上昇トレンド** | 全銘柄共通（レンジ相場の日は0） |

日経のADXは全銘柄共通なので、**レンジ相場の日は本命が構造的にゼロになる**。
採用ルールは26年で13,633トレード＝年約520件しか発生しない選択的なルールで、
毎日3銘柄出るようなものではない。「本日はなし」が正常な状態。

- 利確目安は銘柄ごとのATR（値動きの荒さ）×3から算出。到達率・到達日数は
  過去トレードの実測値であり予測ではない（詳細は4.4-7）
- 銘柄名はEDINET由来の日本語名を使う（`data/japanese_names.json`）
- ⚠️ **売買ルールを変えたときも、対象銘柄リストを変えたときも、
  `scripts/notify.py`の統計値を必ず取り直すこと**（自動追随しない）。
  944銘柄へ広げた際は到達率が2〜5pt下がった（中小型株のぶん値動きが荒く、
  ATR×3の目標が遠くなるため）。取り直し方はREQUIREMENTS.mdの5.1を参照

ルールの根拠と、採用/不採用にした各案の検証結果は
[REQUIREMENTS.md](REQUIREMENTS.md) の 4.4 節に全て記録してある。

### ルールを検証するとき

条件を1つずつ `backtest.py` で回すのではなく、`compare.py` にまとめて渡す。
株価を一度だけ用意して全条件を回すので速く、結果も表で並べて比較できる。

```bash
python3 compare.py "timesl trend marketadx volume rs either ; timesl trend marketadx volume rs pullback" --periods 5y,10y,max
```

- 条件の書式は `backtest.py` の引数と同じ。ファイル（1行1条件）でも渡せる
- `--tickers universe.csv` で対象銘柄を差し替えられる
- 採用基準は**5年・10年で一貫して改善すること**（1期間だけの改善は不採用）。
  26年も併せて見るが、①2017年より前の生存者バイアスが未検証、②経路依存の
  ノイズが±50pt、の2点から主の根拠にはしない（4.4-9 / 6.6-2）
- 株価は `data/price_cache/` にキャッシュされる（gitignore済み）。
  おかしくなったら `python3 price_cache.py clear` で消す

## 検証で得られた主な教訓

1. **勝率とPFはトレードオフ**。勝率を上げる手法の多くは、実質的に損切りを
   遅らせる／しないことで買っているだけ（損切りなしタイムストップは勝率
   54.4%と高いが-20%超の大損が2件→50件に激増した）
2. **トレード単位の改善は実運用の優位性に直結しない**。勝率を42.8%→52.0%に
   改善しても、予算制約と税金を入れると効果はほとんど残らなかった。
   実運用を動かしたのはルールではなく対象銘柄の広さだった（教訓6）
3. **集計で差が見えても、アウトオブサンプルで持続性を確かめること**。
   業種別に明確な成績差（金融58.4% vs テクノロジー46.9%）が出たが、
   年代間の順位相関は-0.30/-0.14と負で、業種フィルターは機能しなかった
4. **既存条件にフィルターを足す方向はほぼ機能しない**。有効だったのは
   同程度の実力を持つ独立したシグナル（押し目買い）を並べることだった
5. **データを疑うこと**。yfinanceの株式分割データ不整合により、5銘柄で
   実際にはあり得ない値動き（日本航空で191,400%等）が記録されていた
6. **売買ルールより「買える銘柄が何個あるか」のほうが効いた**。ルールの
   改良は勝率を数pt動かすだけだったが、対象銘柄を225→944に広げると
   実運用リターンが大きく変わった。予算制約が本当のボトルネックだった
7. **点推定どうしを比較しない**。資金を日々回すシミュレーションは経路依存が
   強く、株価0.01%の誤差で結果が±50pt動く。「+30pt勝った」は、範囲を
   出して重なりを見るまで何の意味も持たない
8. **バイアスは「向き」を実測するまで決めつけない**。生存者バイアスを
   「戦略に有利に働く」と書いていたが、実際に測ると逆だった。上場廃止の
   95.6%は買収・MBO（株主はプレミアムを受け取る）で、倒産は1.7%しかない。
   「上場廃止＝倒産」という思い込みが誤りだった（4.4-9）
9. **「検証していない」と「効いていない」は別物**。総合スコアの50%を占める
   割安度は一度も検証されていなかったが、測ってみるとPERで18.9pt・
   PBRで24.3ptの勝率差があり、テクニカル条件より選別力が強かった（4.4-10）

## 注意事項

- **自分専用ツールとして作成**。個別銘柄の売買を推奨するものではなく、
  スクリーニング（絞り込み）の参考情報として使うこと。
- 投資判断は自己責任で。他人に見せる/配布する場合は、投資助言業の
  規制（金融商品取引法）に抵触しないよう表示内容に注意すること。
- yfinanceのデータは無保証・遅延あり。重要な判断の前には証券会社の
  公式情報で必ず裏を取ること。
- バックテストの数値は既定で取引コストを含まない。実際の成績はこれより
  低くなる（詳細は [REQUIREMENTS.md](REQUIREMENTS.md) の 7節）。
