# 株おすすめツール（自分専用）

日本株（日経225構成銘柄）を対象に、「割安度（PER・PBR・配当利回り）」と
「トレンド（移動平均・下半身・押し目買い等）」をスコア化して合算し、
おすすめ順にランキングするツール。

---

## ⚠️ 最初に読むこと：このツールはインデックス投資に勝っていない

2026-08-29に、予算制約・売買手数料・スリッページ・ETFコスト・**税金**を
すべて織り込んだポートフォリオシミュレーション（`portfolio_sim.py`）を
行った結果、**このツールの売買ルールは日経平均のインデックスファンドを
買い持ちするより成績が劣る**ことが分かった。

| 期間 | 本ツールの戦略（税引き後） | 日経平均を買い持ち（納税後） |
|---|---|---|
| 10年 | +160.2% | **+235.2%** |
| 27年 | +142.5% | **+224.9%** |

- 税引き**前**なら戦略が勝つ（27年 +458.9% vs +282.3%）が、売買のたびに
  課税されて複利が削られるため、税引き後では逆転する
- NISAでの回避も、成長投資枠が年240万円しかなく本戦略の年間買付
  800〜1,000万円をカバーできないため2〜3割が限度
- 詳細は [REQUIREMENTS.md](REQUIREMENTS.md) の 4.4-4 を参照

**それでも個別株をやりたい／銘柄選びを楽しみたい、という前提で使うこと。**
「インデックスより儲かるツール」ではない。

## 現在の仕様

- **対象銘柄**: `tickers.csv` に列挙した225銘柄（日経225構成銘柄）
- **予算**: 100万円（`screen.py` の `BUDGET`）。日本株は100株単位で買うため、
  1単元が予算を超える銘柄は自動で除外される
- **データ取得**: yfinance（無料・登録不要）＋ EDINET（財務データの一部）
- **スコア**: 割安度スコアとトレンドスコアを 50:50 で合算
  （`FUNDAMENTAL_WEIGHT` / `TECHNICAL_WEIGHT` で調整可）

### 売買ルール（バックテストで検証済み）

- **買い**: 「下半身」または「押し目買い」のどちらかが点灯し、かつ
  PPP3/4以上・株価が100日線より上・日経平均がADX20超の上昇トレンド・
  出来高が20日平均の1.5倍以上・日経平均をアウトパフォーム中
- **売り**: 保有60日で手仕舞い、または買値から-10%で損切り（早い方）

ルールの根拠と、採用/不採用にした各案の検証結果は
[REQUIREMENTS.md](REQUIREMENTS.md) の 4.4 節に全て記録してある。

## 検証で得られた主な教訓

1. **勝率とPFはトレードオフ**。勝率を上げる手法の多くは、実質的に損切りを
   遅らせる／しないことで買っているだけ（損切りなしタイムストップは勝率
   54.4%と高いが-20%超の大損が2件→50件に激増した）
2. **トレード単位の改善は実運用の優位性に直結しない**。勝率を42.8%→52.0%に
   改善したが、予算制約と税金を入れるとインデックスに負ける
3. **集計で差が見えても、アウトオブサンプルで持続性を確かめること**。
   業種別に明確な成績差（金融58.4% vs テクノロジー46.9%）が出たが、
   年代間の順位相関は-0.30/-0.14と負で、業種フィルターは機能しなかった
4. **既存条件にフィルターを足す方向はほぼ機能しない**。有効だったのは
   同程度の実力を持つ独立したシグナル（押し目買い）を並べることだった
5. **データを疑うこと**。yfinanceの株式分割データ不整合により、5銘柄で
   実際にはあり得ない値動き（日本航空で191,400%等）が記録されていた

## 注意事項

- **自分専用ツールとして作成**。個別銘柄の売買を推奨するものではなく、
  スクリーニング（絞り込み）の参考情報として使うこと。
- 投資判断は自己責任で。他人に見せる/配布する場合は、投資助言業の
  規制（金融商品取引法）に抵触しないよう表示内容に注意すること。
- yfinanceのデータは無保証・遅延あり。重要な判断の前には証券会社の
  公式情報で必ず裏を取ること。
- バックテストの数値は既定で取引コストを含まない。実際の成績はこれより
  低くなる（詳細は [REQUIREMENTS.md](REQUIREMENTS.md) の 7節）。
